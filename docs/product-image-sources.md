# Product image sources

All 31 catalog images are local PNG files in `images/products/`. The website does not need the external image hosts to display them.

**Matching notes:** Six images match the named product or product family. The Eye of the Storm image was supplied by the project owner. The other 24 are illustrative matches based on product type, function, name, or brand; they are not photos of the exact name-and-brand combinations in the demo catalog. Product names, prices, descriptions, and layout were preserved. Shades and package sizes may vary.

The mini serum uses the full-size serum photo as an illustration. The rollerball set uses a single rollerball photo. See the photographed-product column for every substitution.
